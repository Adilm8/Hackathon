# Первый прогон: 14.11.2026 (вечер), сборка main на 21:45 UTC

Среда: `next dev`, `LLM_PROVIDER=mock`, `STRIPE_MOCK=on`, встроенная БД, Chromium (Playwright). Ширины 360 (мобильный, касание), 768, 1280. Прогнаны сценарии S1, S2, S3 (частично), S4, S5, S6 (один чувствительный вопрос), S8, S12 (экран Privacy, Settings без удаления), S14 (быстрая проверка). Не прогнаны: S9, S10, S15 (экраны дня, отметки, значка отдают 404, в работе), реальные микрофон и распознавание речи (проверит Лида на устройстве), Safari/iOS (нужен реальный iPhone).

## Что работает хорошо
- Лендинг на 360 px без горизонтальной прокрутки, обе кнопки крупные (328×56), три шага и список событий, дисклеймер.
- «Try a sample» ведёт сразу на план с бейджем «Sample data», 5 глав с датами, «5 sleeps until the dentist».
- Вопрос ребёнка → страница-ответ → переписанная следующая страница с чипом «Updated because Max asked: 'Will it hurt?'»; счётчик «1 of 3 questions tonight»; кнопки вопросов ≥44 px.
- Чувствительный вопрос открывает карточку «Only you see this» с Show/Edit/I'll answer myself.
- Пейвол прозрачный: цены, список «How it works» с датами, согласие на автопродление, рамка «Test mode» с картой и Copy, «Not now».
- Прямой переход на главу 2 без оплаты возвращает на пейвол.
- Privacy на простом языке, Settings полный (значения, размер текста, ночные цвета, backup, delete).
- Целевые размеры ≥44 px почти везде; у всех кнопок есть имена, у полей метки, `lang="en"`.
