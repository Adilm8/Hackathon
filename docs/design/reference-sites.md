# UI-референсы для Big Day Stories

Статус: список сайтов-образцов. Скриншоты и страницы, которые пришлёт Лида, будут разобраны в отдельном документе (палитра, шрифты, компоненты).
Конкуренты (BooksGiant, TinyCoach, Courageous Kids, Storytime AI, Oscar Stories, Touch Autism, Special Stories и прочие AI-истории для детей) намеренно исключены.

## Принцип единого стиля
Берём паттерны из разных источников, но приводим к одному набору токенов: одна палитра, один скруглённый шрифт без засечек, один радиус углов, одна система теней. Оригинальность даёт собственный персонаж-проводник и «карточка большого дня», а не копия одного приложения.

## Источники по элементам

| Элемент | Источник | Что берём |
|---|---|---|
| Онбординг и анкета | Duolingo, Headspace | Один вопрос на экран, крупные карточки-ответы, персонаж задаёт вопрос |
| Читалка для ребёнка | Khan Academy Kids | Одна сцена на экран, крупная иллюстрация, 1–2 предложения, большая кнопка «Дальше», шкала прогресса |
| Родительский кабинет | Khan Academy Kids (родительская зона), Linear | Родительский замок, карточки событий и статусов, спокойная плотность |
| Пейволл | Blinkist, Quizlet, BoldVoice, Hevy | Честная шкала пробного периода, напоминание до списания, таблица Free vs Pro |
| Оплата | Stripe Checkout | Простая знакомая форма оплаты |
| Прогресс и награды | Duolingo, Khan Academy Kids | Серии, значок «Я подготовился», праздничный экран, без таблиц лидеров |
| Календарь и дата | Airbnb, Cal.com | Выбор даты, обратный отсчёт, добавить в календарь (.ics и Google Calendar) |
| Пустые состояния | Notion, Linear | Одна иллюстрация, одна фраза, одна кнопка |
| Печатная карточка | Canva (шаблоны календарей и карточек) | Компоновка для печати |

## Доступность
Mobbin открывается без входа только на главной, сам каталог за регистрацией. Page Flows из автоматической загрузки не открылся. По этим двум нужны скриншоты от Лиды.

## Правила для детского интерфейса
- Крупные цели нажатия, шрифт без засечек (Sofia Pro Soft, Andika), иконки вместо подписей.
- Мало текста, понятные слова, озвучка.
- Прогресс виден, поощрение позитивное.
- Родительские настройки за замком.
