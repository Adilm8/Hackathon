# Architecture

Owned by the architect. Builders read it before starting a feature and ask for changes instead of changing contracts themselves. The starting point below is the stack from the ТЗ (section 10) with Lida's decisions of Nov 15; the architect confirms it and fills in the contracts.

## Stack

| Layer | Technology | Why |
|---|---|---|
| UI | Next.js (App Router) + TypeScript + Tailwind | API routes in the same project |
| Hosting | **Railway**, deployed once at the end (Lida, Nov 15) | not Vercel; one Node service, scalable on paper |
| State | Zustand persisted to localStorage; idb-keyval for photos and recordings | guest mode without a database |
| LLM | OpenRouter and Gemini (keys in env), model id from env; Vercel AI SDK for streaming and schema answers; zod validation | provider-agnostic, pages appear while generating |
| Illustrations | SVG character components (animal × colour × accessory × pose) + 9 backgrounds | consistent character, no image generation cost |
| Speech | speechSynthesis, MediaRecorder (parent's voice), SpeechRecognition (option); ElevenLabs later (see roadmap, Future functionality) | free first, no audio sent to the server in the MVP |
| PDF | @react-pdf/renderer in the browser | event-day card (A5) |
| Calendar | .ics generated by a server route | reminders without push or email |
| Payments | Stripe Checkout (test mode), session check in `/api/verify`, signed entitlement | real payment flow |
| Analytics | event counters without personal data (cookie-less) | metrics without child data |

## System overview

Product logic lives in the browser and in event templates. The server is a thin layer of API routes without a database. A dedicated engine builds the plan, keeps state and counts topics without the LLM.

## Decisions

- The first code commit is `lib/engine/types.ts` with the contracts, so the streams (engine and content, API and safety, screens) can work in parallel.
- `lib/engine/clock.ts` is the single source of "today" (used by Demo: skip to…).
- Full ТЗ scope: all 6 event templates, react-pdf card, all P1 features; the analysis cuts are rejected (Lida, Nov 15).

## Configuration

All variables are listed in `web/.env.example` (committed, no values). Real values go in `web/.env.local` (git-ignored) locally and in Railway variables in production.

| Variable | Use |
|---|---|
| `OPENROUTER_API_KEY` | LLM through OpenRouter |
| `GEMINI_API_KEY` | LLM through Google Gemini |
| `OPENROUTER_MODEL`, `GEMINI_MODEL` | model id for each provider |
| `LLM_PROVIDER` | which provider the server calls first |
| `STRIPE_SECRET_KEY` | Stripe, test mode only (`sk_test_...`); checkout refuses live keys |
| `ENTITLEMENT_SECRET` | signs the paid-access token after `/api/verify` |
| `NEXT_PUBLIC_BASE_URL` | Stripe return URLs and .ics links |
| `ELEVENLABS_API_KEY` | later: voice generation and recognition |
